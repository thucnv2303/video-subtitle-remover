2. Selected P1 `ttsVoice`/`ttsSpeed` are snapshotted before run but are not passed into global reasoning, so the script cannot be budgeted for the selected voice before TTS.
3. Legacy `/api/tts-retry` deliberately splits long text into multiple speech clips and inserts timeline gaps; this conflicts with continuous narration.
4. PR #46's repair preserves exact SRT segment structure, so it optimizes an unsuitable segmented artifact instead of rewriting one continuous narration.
5. Global reasoning regenerates scenes even though Vision chunks already produced scene evidence, increasing structured output size and latency.

- Subtitle display chunks are derived only after full narration synthesis and must not introduce speech gaps.
